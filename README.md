# qa_test

Репозиторий с результатами тестового задания на стажировку VK (QA-инженер).

## Что сделано
- Ручное тестирование веб-формы заказа: найдено 11 дефектов.
- Дефекты оформлены с шагами воспроизведения, ожидаемым и фактическим результатом, серьёзностью и приоритетом.
- Планируется тестирование API – коллекция Postman и отчёт будут добавлены позже.

## Структура
- `web/BUGS.md` – баги веб-интерфейса  
- `api/` – отчёт по API и коллекция запросов (в работе)  
- `screenshots/` – скриншоты дефектов  

## Формат баг-репортов
Для каждого дефекта указаны:
- ID и заголовок
- Серьёзность (Critical / Major / Minor / Trivial)
- Приоритет (High / Medium / Low)
- Окружение
- Шаги воспроизведения
- Фактический и ожидаемый результат

Оформление соответствует общепринятым практикам (аналогично IEEE 829).
